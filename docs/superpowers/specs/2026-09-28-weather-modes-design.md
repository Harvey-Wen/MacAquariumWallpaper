# 三种新增天气

需求：在既有晴天和雨天菜单中新增下雪、阴天、多云。

采用现有手动天气选择、模拟时间过渡、Metal 实时效果和静态桌面背景同步链路。
- 下雪：三层有不同大小、速度、横向摆动的白色雪花，池塘光照略冷；不积雪、不结冰。
- 阴天：均匀的柔和偏灰光照，无降水。
- 多云：大范围缓慢移动的云影，保留明暗间隙，无降水。
- 晴天、雨天保持已有表现；所有天气数值平滑过渡。暂停和减少动态效果沿用当前冻结规则。
- 菜单和状态文字统一由天气枚举提供；系统背景使用目标天气的静态帧。

采用程序化效果而非额外贴图或天气服务：匹配现有俯视池塘、不需要网络或新增依赖。只增加菜单名称不足以让天气可辨。

验证：五种状态/过渡/雨滴隔离、暂停恢复、实际 Metal 帧及长时间连续性、桌面背景切换和恢复、原有回归、构建签名。
