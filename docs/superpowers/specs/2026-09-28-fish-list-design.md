# 鱼的列表与逐条删除

用户已确认：列表和删除同时包含默认的 30 条锦鲤与手绘新增鱼；重启保留删除结果。

## 界面与行为
- 菜单栏在“画一条鱼…”旁增加“鱼的列表…”，打开单例原生 AppKit 窗口。
- 可滚动列表显示实际 Metal 外观缩略图、稳定名称、默认/手绘来源和逐条删除按钮。默认鱼使用原始编号加一，手绘鱼使用 UUID 短标识，删除不会重编号其他鱼。
- 显示当前总数和两类数量。新增后立即同步列表；窗口关闭再打开显示当前状态。
- 删除前确认鱼的名称并说明重启不恢复；取消无变化。空列表显示引导，并保留“画一条鱼…”入口。
- 删除不改变暂停、显示/隐藏或天气状态；默认鱼也可以全部删除。

## 数据与同步
- `FishIdentity` 区分固定默认编号与手绘 UUID，删除按身份而非列表行号执行。
- 默认鱼保存已删除编号集合，位于现有 CustomFish 目录的 state 子目录，避免被扫描为绘画。
- 手绘鱼删除对应绘画文件并释放纹理。旧绘画文件格式保持兼容。
- 持久化成功后再修改模拟与列表；读取/保存失败明确提示，不能覆盖损坏的默认鱼删除记录。
- 启动先创建原有默认鱼群再过滤已删除编号，保留幸存鱼的原始花纹。静态桌面背景缓存键包含当前全部鱼身份，默认鱼删除也触发刷新。
- 列表缩略图使用同一个渲染器、固定朝向和尺寸，按身份缓存；天气、水纹及游动状态不参与列表缩略图。

## 验收
- 混合鱼群中删除指定默认鱼/手绘鱼，只减少目标；重启后仍删除，其他鱼身份、手绘笔迹保留。
- 验证取消、保存失败、损坏记录、最后一条鱼、删空后新增、暂停和隐藏时删除。
- 原生窗口检查数量、预览差异、滚动、删除按钮的稳定身份、即时刷新和空态。
- 运行绘画、模拟、自定义鱼桌面/渲染、窗口检查及构建签名验证。数据和背景集成测试使用临时目录与替身，不操作用户的真实鱼。
