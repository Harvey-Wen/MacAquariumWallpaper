# 随机降水与落水生命周期

用户要求：雪花自然随机；水面逐渐留下少量积雪，随时间或鼠标划过消失；天气切换保留旧的在途雨雪，新天气从画面顶部进入。

独立粒子取代雨雪全屏网格：随机出生时间、横向位置、尺寸、速度、摆动频率与相位。粒子持有自己的年龄和水面落点，切换只控制出生种类，不改写/清空已有粒子。雨落水产生既有轻波，雪落水转换成有限寿命的表面雪片。阴天、多云与晴天停止新降水，让旧粒子走完生命周期；光照继续缓慢过渡。

水面积雪保持零散薄片，约10～20秒后开始融化；鼠标有效移动线段附近积雪在约1秒内柔和消散，静止、遮挡后的重入或大幅位置跳跃不跨区清扫。数量有上限，达到上限不驱逐已有在途粒子。暂停冻结全部状态，调整屏幕尺寸时同步映射位置和尺寸。

模拟生成数据，Metal使用批量小四边形绘制，避免每片雪花一次绘制调用。验证覆盖随机性、身份连续性、顶部进入、落水积雪、自然/鼠标消散、快速反复切换、暂停/尺寸、原有鱼/叶/雨波行为、真实渲染帧与30FPS预算。
