# 手绘鱼加入池塘

日期：2026-09-28
状态：具体方案待用户确认；尚未修改应用代码。

## 目标与参考

用户希望参考 https://www.douyin.com/video/7689693434101255470 ，自己绘画并新增一条鱼到现有池塘。

实际观察：视频18秒打开一个俯视鱼形编辑窗口，提供白色鱼身、眼睛、半透明鱼鳍、调色板和滑块；20–24秒在鱼身上画红色条纹。视频中的小字与滑块含义无法可靠辨认，不据此虚构参数；本次按用户明确要求完成绘画及新增闭环。

## 方案选择

1. **预置鱼形上手绘花纹（推荐）**：与已观察的视频一致，复用现有锦鲤模型、摆尾及水下光照。可以自由画颜色和笔触，轮廓保持锦鲤。
2. 自由画整个鱼形：允许任意轮廓，但需要额外确定头尾、网格和摆尾形变，工程量与本次视频参考不匹配。
3. 只选预置颜色或花纹：实现简单，但缺少用户要求的绘画体验，不采用。

推荐范围不包含自定义体型比例、导入照片、AI生成、喂食、排行榜或新的鱼种。

## 用户操作

- 菜单栏增加“画一条鱼…”入口，打开独立原生窗口，重复打开激活同一个窗口。
- 窗口展示放大的俯视锦鲤，默认白色鱼身，眼睛和鱼鳍清晰可见；提示“在鱼身上画出你的花纹”。
- 提供常用颜色、颜色选择器、画笔粗细、橡皮擦、撤销和清空。鼠标按下并拖动连续绘画，笔触限定在鱼身范围，窗口背景不会画进鱼身。
- 底部“加入池塘”每次新增一条鱼。成功后关闭窗口，新鱼从可见水域出现；再次打开可画下一条。
- 取消或直接关闭不新增、不修改已有鱼。纯白鱼也可以加入。
- 保持默认锦鲤的常规体型，无额外参数面板。新增鱼复用游动、摆尾、鼠标避让、点击响应与水波折射。
- 若池塘隐藏，加入后显示池塘；若已暂停则保持暂停，新鱼静止可见，恢复后游动。
- 自定义鱼及花纹保存在本机，重启自动恢复，每条已保存记录只恢复一次。

## 实现边界

- 新增独立绘画数据/保存组件和AppKit画鱼窗口，保持现有项目的轻量结构，不引入网络、外部依赖或新权限。
- 以稳定标识关联每条自定义鱼的花纹；保存序列化绘画数据到应用的Application Support独立子目录，不混入桌面背景恢复记录。
- 保留既有FishState初始化兼容性，增加可选自定义外观标识；通过模拟新增方法追加鱼，使用唯一运行时ID和有效水域出生位置，不重建原鱼群。
- 绘画数据栅格化为颜色纹理并缓存，渲染器按鱼绑定对应纹理；原锦鲤继续使用原程序花纹。
- 鱼身绘画坐标与模型俯视坐标统一，笔迹不会随摆尾漂移。眼睛、鳍、阴影、鱼身明暗及水下折射继续使用原流程。
- DesktopController负责将保存、纹理加载及模拟追加串联，并更新静态画面；失败时保留草稿并显示可理解的错误，避免界面宣称成功但鱼未保存。
- 加载损坏记录时显示提示并保留原文件，不能静默覆盖丢失的数据；其他有效自定义鱼仍正常加载。
- 原项目另有鱼群数量与避让改动正在进行。本任务在独立工作区完成，不覆盖这些改动；最终集成使用最新已提交版本并处理实际冲突。

## 验证与完成标准

1. 绘画验证：点击、连续拖绘、多种颜色、笔宽、擦除、撤销、清空及关闭取消工作正常，鱼身以外笔迹不影响最终鱼。
2. 保存验证：使用临时目录验证多鱼保存/加载、独立标识、重启不重复，以及损坏记录/写入失败不丢草稿或覆盖原记录。
3. 模拟验证：每次加入数量恰好加一；原鱼位置不被重置；新鱼在水域内持续游动并响应现有互动。
4. 渲染验证：以非对称彩色笔迹检查方向、位置和颜色；两个自定义鱼保持不同花纹；原锦鲤无外观串色；摆尾前后笔迹附着，水波仍作用于新鱼。
5. 集成验证：通过菜单打开、绘制、加入后在池塘可见，暂停/隐藏场景语义符合上述约定，重启后保留。
6. 回归模拟、输入与离屏Metal渲染，完成构建和签名验证。会修改系统壁纸的原生检查只在常驻应用正常退出后串行运行，避免背景恢复记录竞争。
7. 每完成一个最小可验证模块及时提交Git，更新使用说明与验收记录；交付时明确实际完成的验证与未覆盖项。
