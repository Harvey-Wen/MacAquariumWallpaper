# Fish List Implementation Plan

> **For agentic workers:** Execute this plan inline, task by task, with validation and a commit for each completed module.

**Goal:** 展示所有锦鲤并支持按身份永久删除。

**Architecture:** 沿用 AppKit 窗口、现有模拟与 Metal 渲染。FishIdentity 区分默认编号/手绘 UUID；存储成功后再更新模拟、桌面背景和列表。

**Tech Stack:** Swift 5 / AppKit / Metal，macOS 14+，无新增依赖。

## Global Constraints
- 列表和删除同时包含默认的 30 条锦鲤与手绘新增鱼；重启保留删除结果。
- 删除不改变暂停、显示/隐藏或天气状态。
- 不操作用户真实鱼来做测试；背景集成使用替身。
